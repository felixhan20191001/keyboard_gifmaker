# Skills

Three independent keyboard-GIF skills. Install only the one you need.

| Package | Screen | Zip |
|---------|--------|-----|
| `generating-rt100pro-gifs` | RT100 Pro 240×240 | `packages/generating-rt100pro-gifs.zip` |
| `generating-rt85-gifs` | RT85 320×172 landscape | `packages/generating-rt85-gifs.zip` |
| `generating-qk100-gifs` | QK100 Mk2 135×240 | `packages/generating-qk100-gifs.zip` |

Unzip or symlink a folder to `~/.grok/skills/<name>` and `~/.codex/skills/<name>`.
